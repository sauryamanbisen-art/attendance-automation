Security & Immutability Architecture

This application operates on a Secure Local-First Configuration model.

  • Authentication credentials, API tokens, and OAuth secrets are never transmitted to or readable from the browser.
  • Environment variables (.env) are immutable from the UI to prevent unauthorized tampering or CSRF attacks.
  • Session cookies are kept isolated inside Playwright's local storage_state sandbox with POSIX 0600 permissions.
  • To safely update credentials or OAuth logic, edit the server-side .env file directly.
